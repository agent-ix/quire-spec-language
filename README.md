# quire-spec-language

Private bootstrap, 2026-09-07. Repository shell and specification work only; no implemented or released capability is claimed.

## Charter

Native language model, syntax, parser, compiler and reference-evaluator workspace, with explicit executable projections.

## First work

Define crate/module ownership for model, syntax, parse, compiler and eval; reconcile the shared Filament model package and existing contract binding; choose one aggregate-invariant acceptance fixture; specify supported types, snapshots, definedness and refusal cases; define test/CI and package-release policy before adding speculative crates.

## Boundaries

No duplicate evidence store, hidden normative dependency, or unqualified backend promise. Existing Quire/Quoin/Filament interfaces must be inspected before replacement or extraction. Research and private issue links must not enter a public release packet.
