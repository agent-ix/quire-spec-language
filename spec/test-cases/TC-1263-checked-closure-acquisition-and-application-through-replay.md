# TC-1263: Checked closure acquisition and application through replay

## Description

Verify FR-485-AC-1 through FR-485-AC-12, FR-485-AC-18 and FR-262-AC-13 through a consumer that may enter QSL only through `qsl_replay`, comparing the facade with the existing compile and evaluation paths.

## Test Procedure

1. Compile a unit whose first function is `f(x: Int[0, 9]): Integer` and an imported dependency whose first function is `helper(): Integer` and second function is `g(x: Int[0, 9]): Integer`; use `g` as the imported callable. Compare acquisition with `compile_admitted`, instrument the shared compile path, drop the source and public output values, then create a registry from the retained handle. Read the two declaring checked graphs and assert that `f`'s root location is `Origin::Body { function: "f", index: 0 }` and `g`'s is `Origin::Body { function: "g", index: 1 }`, both at the root path and unequal, before any facade application.
2. Call `lookup_callable` with the unit's `package_id` and the own callable, dependency callable, enum, parameter and missing node ids; repeat the imported callable lookup with its dependency's `package_id`, then register and apply that returned selection in the acquired closure. Try an unknown owner. Compare each selection's read-only key and signature with the checked graphs under a QSL-internal test.
3. Compile an external consumer crate importing only `qsl_replay`, `quire_eval`, `quire_exact` and `quire_semantic_value`; acquire, look up, bind a generated body, begin, step and run. Reject forbidden imports and facade access to the adapter/checked package in compile-fail fixtures.
4. Exercise FR-485-AC-4's admission order, failed and successful Begin, sealing, two later sessions, and a dropped runnable session. Under a QSL-internal test only, inject a selection whose key is absent from the closure to exercise leaf `CallableNotAdmitted`. Acquire the same source a second time; take its own callable selection, whose `package_id`, `NodeKey` and signature equal the first's, and pass it to the first registry's register and Begin before and after sealing. Repeat with a selection from an unrelated package. Record factory invocations and meter charges.
5. Apply `f(3)` without and with a generated body; have the generated body request another admitted callable. Compare the interpreted run with QSL's current result, location, loss and spend. Repeat at `work_units` one below and exactly equal to measured spend, and with wrong arity and wrong type. Cancel the meter's installed handle with `Requested` before `begin_call` in one run. In two other runs, begin successfully with an uncancelled handle, once for the unit's `f` and once for the imported `g`; cancel the handle before each session's first `function.call` charge, then step. Repeat the root charge denial with a `work_units` limit of zero. Compare each terminal `Evaluation.location` with the actual `function_by_identity(callable).body.location()` in the callable's declaring checked graph, using a QSL-internal oracle; the step-1 inequality must hold so substituting the unit's location for `g` fails. In a leaf contract test, admit a callable whose checked closure returns no root location, then call Begin.
6. Attempt acquisition with malformed source, a same-owner library, a short S1 limit and an S1 limit above the reader limit. Begin `h(p: Population<T>[3]): Boolean` with `Value::Population` carrying a `PopulationId` not recorded in `ApplicationEnvironment` constructed from `ObjectClosure`. Observe Begin before any body read, both before and after FR-405's evaluator switch.
7. Acquire a unit whose `twice` body calls `f` twice, whose `k` calls an imported `helper`, importing a library whose `outer` calls `helper` twice. For each caller selection, ask `nested_call_site` for every call node and ordinal and compare the issued locations with an independent walk of the declaring checked body. Register a generated body for the caller requesting the callee at each issued `Location`, run it under the work limit equal to the root-only spend, and compare the incomplete outcome's `location`. Repeat for the imported `outer` and assert the dependency's `package_id` and `Origin::Body`.
8. Refuse a second-acquisition caller, both foreign-owner directions, an unrelated body's call, a function node, an unknown node, a node several other packages own (decided on the pure attribution step, since owner-scoped keys cannot coincide in a real closure) and an unknown ordinal; assert the distinct causes, an open registry, no factory invocation and an unchanged meter. Compare the site before and after registration, after Begin and through a cloned handle.
9. Declare `record P { r: Boolean; o: Boolean?; }`, obtain its `nominal_declaration` view from an admitted selection and compare each `RecordField`'s identifier, `ValueType` and `Presence`; repeat for a tuple and a union view.
10. Inspect production source and run FR-060 T12-A on the consumer checkout for API and ownership boundaries.

## Expected Results

1. Package bytes, identity and context equal; one spine compile; the retained closure remains valid. The own and imported checked-body root locations have the specified distinct origins and are unequal before application.
2. Own and imported callables resolve to opaque selections containing their minted keys/signatures when the correct owner id is supplied; the imported id with the unit owner refuses `Foreign` naming its actual owner; missing owner/id and wrong-kind lookups refuse as specified. The imported selection registers and applies in the same closure. A raw `NodeKey` cannot be passed to register or Begin.
3. Allowed imports compile and apply; forbidden paths fail to compile or fail T12-A.
4. Matching-selection registration and sealing follow the leaf's exact order; the internal absent-key probe returns leaf `CallableNotAdmitted`, while public lookup returns `Unknown` and issues no selection. The equal-key second-acquisition and unrelated selections both return `SelectionRefusal::WrongAcquisition` at register and `ApplicationBeginRefusal::WrongAcquisition` at Begin, before leaf delegation, with no binding, body invocation or charge; the same refusal takes precedence when sealed. The first binding remains effective for the first acquisition's selection.
5. Results and charges match the shared leaf path. Cancellation before Begin returns `ApplicationBeginRefusal::Call(CallFailure::Cancelled(Requested))`, no session or charge. After successful Begin, cancellation or a zero work limit at the root `function.call` returns an incomplete evaluation with `location: Some` equal to the own or imported callable's authoritative checked-body root location, never the other package's location, with `tripped() = Requested` for cancellation and no admitted charge. The missing-location leaf fixture returns `CallFailure::Fault` with stage `quire-eval` and invariant `root-call-site-absent`, no session or charge, and an open registry. Denied work retains the preceding charge prefix; no continuation runs after terminal or drop.
6. Acquisition refusals equal `compile_admitted` in class and detail. The missing `PopulationId` returns `ApplicationBeginRefusal::Call(CallFailure::Input(InputRefusal::WrongValueKind))` for parameter `0` at Begin, with no session, charge or body read, on both designated evaluators; no admitted empty population is fabricated.
7. Each issued site equals the checked call node's location and the denied nested charge reports it; the imported caller's site carries the dependency's package and body origin.
8. Refusals are the six distinct causes with no registry or meter change; the site is stable across registration, Begin and clones.
9. `r` and `o` share one `ValueType` yet report `Presence::Required` and `Presence::Optional`; tuple and union views are unchanged.
10. The facade uses the existing std reference adapter before FR-405's switch and one designated evaluator afterward, with one compile path, no dual dispatch, compatibility layer, copied leaf or QSL moved-type re-export.
