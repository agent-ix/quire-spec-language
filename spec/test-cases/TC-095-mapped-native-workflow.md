## Description

Compile a mapped parent/aggregate clause and execute actual native runtime inputs.

## Test Procedure

Supply exact body/original bytes, a verified map, authored binding and admitted
native model. Compile, validate and evaluate healthy and violating populations;
offer a dangling reference to the complete population.

## Expected Results

The native package retains authored/body identity and the wrapper retains the
original document. Healthy/violating results differ; refused runtime input has
no Boolean outcome. Original spans preserve exact selected bytes.
