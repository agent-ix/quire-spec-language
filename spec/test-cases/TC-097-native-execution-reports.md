## Description

Execute real parent/aggregate and operation packages through the combined API.

## Test Procedure

Construct admitted native models, checked packages and concrete runtime artifacts.
Run healthy and violating populations; change an operation frame illegally.
Compare original package/input identities, bytes, authored selection and actual
validation/evaluation observations through the returned report.

## Expected Results

Completed predicates return their actual Boolean. Refused frames retain the
exact invocation and selected pre/post bytes with no predicate Boolean. Reports
remain usable after the execution call and its temporary validation context end.
