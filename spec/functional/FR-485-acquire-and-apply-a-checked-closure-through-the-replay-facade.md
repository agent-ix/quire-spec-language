# FR-485: Acquire and apply a checked closure through the replay facade

## Description

A CG consumer permitted by [FR-060](FR-060-check-qsl-api-surface-boundary.md) T12-A can obtain checked-package bytes through `qsl_replay::compile_package`, but those bytes are not an in-process checked closure. The `quire-eval` leaf has the [FR-262](FR-262-evaluate-values-and-calls-at-any-depth.md) registry and session interface; [FR-401](FR-401-host-the-evaluation-interface-in-the-quire-eval-leaf.md) places the QSL adapter to that interface in `qsl-eval`. The `qsl-replay` facade SHALL expose checked-closure acquisition and application without giving a consumer access to `qsl_replay::spine`, the checker, or a second evaluator. This is an in-process API; it adds no wire format or checked authority.

## Inputs

- `acquire_checked_closure(source, path, bytes, packages, dependencies, limits, replay_limits)`: exactly the seven inputs and limit meanings of `compile_admitted` and `compile_package`.
- A `CheckedClosureCompilation` returned by acquisition; `lookup_callable(owner_package_id, wire_node_id)` with the exact `DigestRecord` id of the unit or one admitted dependency and the callable's `WireNodeId`; the opaque `CallableSelection` returned by that lookup; a `CheckedCallOccurrence` (the checked `call` node's `WireNodeId` and the ordinal of its `expression` occurrence); optional host `BodyFactory` bindings with their leaf `Signature` values; an application environment; completed `Vec<quire_exact::Value>` arguments; and a caller-owned `quire_exact::Meter` with its optional installed cancellation handle.

## Outputs

- A `CheckedClosureCompilation` with the identical emitted `CompiledPackage` and `AdmittedContext` of `compile_admitted` for the same inputs, plus an opaque `CheckedClosureHandle` that retains the checked package and its exact direct and transitive dependency closure.
- A facade-owned `ApplicationRegistry` over that handle; registration returns `Result<quire_eval::Admission, SelectionRefusal>`. A successful Begin returns an opaque `CheckedApplicationSession`; stepping returns runnable or terminal, and running returns `Result<quire_eval::Evaluation, quire_eval::CallFailure>`. The caller's meter records the leaf's consumed counters and charges.
- `CheckedClosureHandle::nested_call_site(&caller_selection, call_occurrence)` returns `Result<CheckedCallSite, CheckedCallSiteRefusal>`. `CheckedCallSite` is opaque with private fields and exposes `owner_package_id()` and `location()`, the `quire_semantic_value::location::Location` a generated body places in `quire_eval::ChildRequest::site`.
- Acquisition refusals use `AdmittedRefusal`; a facade callable lookup uses `Unknown`, `Foreign(package_id)` or `WrongKind` as applicable. Registration of a selection issued by another acquisition returns `SelectionRefusal::WrongAcquisition`; Begin of one returns `ApplicationBeginRefusal::WrongAcquisition`. Otherwise Begin returns `ApplicationBeginRefusal::Call(CallFailure)` for a leaf admission failure, and application uses the leaf's existing `CallFailure` and `Evaluation` vocabulary. These facade refusals are typed in-process results, not wire causes.

## Behavior

### Acquisition and identity

1. `acquire_checked_closure` SHALL call the same `recompile_unit` path as `compile_package` and `compile_admitted` exactly once, under the same S1-to-E4 limits and dependency-owner check. It SHALL derive the emitted package, admitted context and retained checked closure from that one result. It SHALL NOT parse emitted bytes back into a second checked graph, construct a `NodeKey`, or run a second checker or evaluator.
2. The handle SHALL own or share the checked package and its dependency closure, so dropping the acquisition result's emitted bytes, admitted context, original source buffers or dependency input after acquisition does not invalidate a registry or live session. Its package identity SHALL equal the emitted package's `package_id`. Each acquisition SHALL hold a distinct private identity shared by that acquisition's handle, selections, registries and sessions; cloning a handle shares that identity, while a separate acquisition has a different identity even when its package id and callable keys are byte-for-byte equal. A handle from a different acquisition SHALL NOT be substituted into an existing registry or session.
3. The facade SHALL expose one lookup operation, `lookup_callable(owner_package_id, wire_node_id)`, over exactly the acquired unit and its checked dependency closure. It SHALL first select the checked package by `owner_package_id`, then resolve `wire_node_id` in that package. An admitted callable returns a facade-owned opaque `CallableSelection` containing the selected owner's `package_id`, that package's check-minted `NodeKey`, its exact `quire_eval::Signature` and this acquisition's private identity, whether the owner is the unit or an imported dependency. The fields SHALL be private; no public constructor, deserializer or conversion from a raw `NodeKey` SHALL create one. Read-only access to the key and signature MAY be exposed for a generated body or diagnostic, but neither is accepted alone as registration or Begin authority. An unknown owner or node refuses `Unknown`; if the node is absent from the selected package but belongs to exactly one other package in this closure, lookup refuses `Foreign` naming that actual owner's `package_id`; a node present in the selected package but not callable by name refuses `WrongKind`. If the same node id is found in several other packages, lookup refuses `Unknown` rather than attributing it to an arbitrary owner. `FunctionSite.function` may supply the `wire_node_id` but does not override the explicit owner. A dependency selection MAY be registered and applied in this same closure's registry; the leaf's signature and admission checks still apply. The selection SHALL NOT supply a root call location; [FR-262](FR-262-evaluate-values-and-calls-at-any-depth.md)-AC-13 requires the checked closure to supply it from the declaring graph. The facade SHALL NOT decode, hash, or synthesize an admitted key in the consumer.

### Nested call sites

9. `CheckedClosureHandle::nested_call_site(caller, call)` SHALL issue the exact checked `Location` of one nested function-application expression inside the selected caller's checked body, for a caller declared by the unit or by an imported dependency of this closure, and for a call to an own or imported function. It SHALL resolve in the caller selection's declaring package only: the `call` node by `WireNodeId`, then its `expression` occurrence by `quire_exact::Origin` role and ordinal through `CheckedGraph::occurrence`, then require that a `NodeKind::Call` or `NodeKind::ImportedCall` of the caller's own checked body (`function_by_identity`) sits at exactly that `Location`. The `Origin::Body` function index and the child path are those the checker recorded; the facade SHALL NOT construct, substitute or synthesize an `Origin` or path, and a root, `Origin::Expression` or other-package location SHALL NOT stand in. The inputs are what CG already holds: the owner package id and caller `WireNodeId` (through the `CallableSelection`) and the call node's `WireNodeId` and `expression` ordinal from the checked package's source map; the ordinal distinguishes equal calls, which share a node key, and the caller's body distinguishes the same call node used in several bodies. `CheckedCallSite` fields SHALL be private, with no public constructor, deserializer or conversion. The method is a read of the retained immutable closure: it registers nothing, begins nothing, charges no meter, and the same acquisition returns an equal `CheckedCallSite` before registration, after registration, and after a successful Begin sealed the registry or a session ran. A caller selection from another acquisition is refused even when its package id, key and signature are equal.
10. A refusal SHALL be one distinct typed `CheckedCallSiteRefusal` cause, before any registration, Begin or charge and with no registry or meter change: `WrongAcquisition` (caller from another acquisition); `UnknownCaller` (the caller's owner or checked body is not in this closure); `UnknownCall` (no package owns the node, or several other packages do); `ForeignCall(package_id)` (exactly one other package of the closure owns the node, so the caller's owner is wrong for it); `WrongKind` (the caller's package owns the node but it is not a function application); `UnknownOccurrence` (no `expression` occurrence with that ordinal); `Unreachable` (a call occurrence that is not in the selected caller's body). Acquisition identity is checked first, then owner, node, kind, occurrence and reachability in that order.

### Application

4. `CheckedClosureHandle::registry()` SHALL create a fresh facade-owned `ApplicationRegistry` from the retained closure through the designated QSL `CheckedClosure` adapter and `quire_eval::Registry`. Before [FR-405](FR-405-retire-the-std-reference-evaluator-for-quire-eval.md)'s switch, that adapter is `qsl_eval::value::PackageClosure::new` over the std reference evaluator; it uses the leaf's ordinary Begin admission, not `pre_admitted`. Its `root_call_site` reads the checked body root `quire_semantic_value::location::Location` through `CheckedGraph::function_by_identity` in the declaring own or imported package, never from a facade-constructed name or occurrence. At the switch, this same facade SHALL delegate to the replacement `quire-eval` evaluator; it SHALL offer no selector, fallback, dual run or retained adapter. A registry SHALL use the same checked closure for all registration, Begin and subsequent sessions. The facade SHALL not expose the adapter, checked package or `qsl_replay::spine` as a consumer API, and SHALL not re-export a moved `quire_eval` or `quire_semantic_value` type from QSL.
5. The facade SHALL accept a `quire_semantic_value::object_closure::ObjectClosure` and form an opaque `ApplicationEnvironment` through QSL's existing `ObjectEnvironment::new`; it SHALL invent no population, object, snapshot or read. For a function `h(p: Population<T>[3]): Boolean` begun with a `Value::Population` whose `PopulationId` is not recorded in that environment, Begin SHALL return `ApplicationBeginRefusal::Call(CallFailure::Input(InputRefusal::WrongValueKind))` naming parameter `0`, with no session, body invocation or charge; the inner leaf cause is the one [FR-403](FR-403-implement-the-no-std-evaluator-in-quire-eval.md)-AC-6 specifies for this input. This is argument admission, before any body read. A later admitted-snapshot producer may supply an environment through a separate requirement; this API SHALL NOT silently treat missing model data as empty admitted data.
6. `ApplicationRegistry::register(&selection, signature, factory)` and `begin_call(&selection, arguments, environment, meter)` SHALL compare the selection's private acquisition identity with the registry's before passing its `NodeKey` to the leaf. On a mismatch, registration SHALL return `SelectionRefusal::WrongAcquisition` and Begin SHALL return `ApplicationBeginRefusal::WrongAcquisition`, without delegating, invoking a factory, charging the meter or changing an open or sealed registry; this refusal takes precedence over the leaf's admission order. A matching selection SHALL delegate to the leaf registry, including its ordered `RegistrySealed`, `CallableNotAdmitted`, `SignatureMismatch`, `DuplicateBinding`, `Accepted` registration results. Begin SHALL delegate admission, the FR-262 `root_call_site` lookup and sealing to leaf `begin_call`, wrapping a leaf `CallFailure` in `ApplicationBeginRefusal::Call`; it takes no separate cancellation handle, caller-provided root location or untrusted package. A failed Begin, including a missing authoritative root location, leaves an open registry open. A successful Begin seals it before any body invocation or charge; ending or dropping a session never reopens it. A new binding set needs a fresh registry.
7. `CheckedApplicationSession::step` and `run` SHALL delegate to the same `quire_eval::Session`, preserving the leaf's ordered charges, locations, losses, child requests, cancellation and terminal outcome. The facade SHALL not evaluate a checked expression or callable by its own node dispatch. A session is consumed at terminal; dropping a runnable session runs no continuation. The caller may retain and inspect its own meter after the session ends.
8. On acquisition failure, the facade SHALL return the same `AdmittedRefusal` class and stage/catalog detail as `compile_admitted` over the same input and limits and SHALL return no handle. A lookup refusal or registration refusal SHALL invoke no body and make no application charge. A root argument-admission failure SHALL return `ApplicationBeginRefusal::Call` carrying the leaf `CallFailure` with no application charge. If the meter's installed handle is cancelled before Begin and admission polls it, Begin SHALL return `ApplicationBeginRefusal::Call(CallFailure::Cancelled)` with the leaf's cause, no session and no charge. If cancellation occurs after a successful Begin and before the next charge, that charge SHALL yield the leaf's located incomplete evaluation, leaving the denied charge unrecorded. A `work_units` denial during a live session SHALL retain preceding spend and return the same located incomplete evaluation. Cancellation SHALL follow only the meter's installed handle and the leaf's poll and charge points.

## Dependencies

- [FR-060](FR-060-check-qsl-api-surface-boundary.md) T12-A and shared compile path; [FR-394](FR-394-expose-the-admitted-enum-key-table-through-the-replay-facade.md) context; [FR-262](FR-262-evaluate-values-and-calls-at-any-depth.md) and [FR-401](FR-401-host-the-evaluation-interface-in-the-quire-eval-leaf.md) shared leaf interface. The quire-eval implementation of FR-262's root-site contract precedes the qsl-replay facade implementation; no leaf source is copied into QSL. [FR-405](FR-405-retire-the-std-reference-evaluator-for-quire-eval.md) later changes the designated evaluator behind this same facade.
