# FR-292: Retired: canonical form of analyze requests and records for a result cache

## Description

**RETIRED (QSpec #513 removes the result cache).** This requirement gave
`analyze` requests and records a canonical RFC 8785 form for a content-keyed
result cache. There is no result cache, so the canonical request form, the
`quire.analyze-request/1` format and the typed record reader it required are
withdrawn. There is no successor requirement.
