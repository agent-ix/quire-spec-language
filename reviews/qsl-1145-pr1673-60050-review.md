## Summary

Ticket: QSL-1145. PR 1673, head 63d4c227b (verified with `gh pr view 1673 --json headRefOid`), base merge-base bcad531b6.

The PR pins `quire-contract-model` at exactly 8b49bd487cc2de387524ad270aa2193277d77965 (Cargo.lock, one line), emits `owner_model` on every `protocol_clause` node (node field, exact dependency, application-preimage member, `NodeKeyRefusal::OwnerModelPresence`, projection check), maps IR `wrong_snapshot` to `Code::WrongSnapshot`, and adds `ProtocolConstruct::NoOwnerModel` (refuse typed, write no clause) for a clause whose `over` is not a reference to an object type of a selected model. The edge targets the object type's model node, which is what QSpec FR-464 / TC-946 OM-01 / the published fixtures write and what IR 8b49bd48 admits (`is_model_declaration_node`: tag `model` or `relation`). That is the choice QSL has to make against FR-375 ("selected concrete model"); QSL follows FR-464. The conflict itself is QSpec's, already escalated.

Production code is sound. The edge is the field, a dependency, a preimage member and a projection check; five of six mutations of it are killed (see Coverage). The defects are in the test rewrite and the spec consistency.

## Verdict

CHANGES REQUESTED. One high (FND-001: test coverage of capture types dropped with no replacement, and the comment that claims a replacement is false), two medium (FND-002 loosened refusal assertion; FND-003 scalar `over` now refused at S4 with FR-218 unamended and no tracked follow-up), three low. Production owner_model code: no defect found. Gate: see Coverage.
