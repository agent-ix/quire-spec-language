## Summary

Reviewed PR #2157 at `aa67197ac3432c7f635035287368f70b5e590b4a` against main `1d2a256d4`, including the FR-383 result contract, checker index mapping, emitter cache behavior, and the public-path tests. Two high-impact correctness defects remain: a refused aggregate can still leave a cached package accessible, and the compacted attempt path addresses source-indexed protocol slots by the wrong index.

## Verdict

**FAIL** — a refused unit can still be emitted as a package, and an independent protocol with an attempt can be lost after a neighboring protocol is refused.

## New findings (disposition pass 1)

| ID | Severity | Summary | Refs |
| --- | --- | --- | --- |
| FND-003 | high | Public checked-package emission entry points bypass the protocol-refusal guard and can return an emission for a refused unit | qsl-package/src/emit.rs:3678-3700, 4700-4723 |

`emit_checked_with_temporal_selections_and_cancel` calls `emit_package_inner` directly without checking `graph.protocol_refusals()`. For a checked graph with a good protocol beside a refused protocol, including a graph requiring no temporal selections, this public API can return the good protocol's package. `emit_package` and `emit_package_with_temporal_selections` also bypass the guard. This leaves a way to obtain a package for a unit whose protocol results aggregate as Refused, despite the new guards on `emit_checked` and `emit_checked_with_cancel`.
