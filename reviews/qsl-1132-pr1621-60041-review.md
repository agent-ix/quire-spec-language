# Reviewer pass over PR 1621 (QSL-1132)

## Summary

Verdict FAIL. Three blockers: the all-features test build does not compile, the events are wrong for implications under a quantifier (reported NotReached though evaluated), and no spec FR/AC or trace tag exists for the new public API although the ticket required spec-first. The unquantified straight-line path is correct and its one test kills five of six probe mutants.

Gate. `cargo fmt --all --check` passes on the PR head and on a scratch merge of origin/main (the branch is one commit behind main; the merge is textually clean). `make ci` on the scratch merge (own target dir) stops at ci-all-features: `qsl-replay/src/spine/clause/tests.rs:862` and `:870` use the irrefutable `let ClauseRunSource::Program { .. } = &mut request.source;`, but `ClauseRunSource` is `#[non_exhaustive]` and gains `Extracted` under feature `quire-extraction`, so E0005 breaks `qsl-replay` (lib test). Not pre-existing: the lines are new in this PR. CI stops at the first red lane, so later lanes were not run.

Probes (scratch, not pushed). In a quantifier body, `forall(n in M::all_nodes : present(deref(n).next) implies true)` over a two-node snapshot (a->b, b), in both node orders, completes true with the single event state NotReached. The evaluator records decisions only on the claim's own level (`ClauseEvaluation::decision` doc, qsl-eval separation.rs:107), so quantifier-body implications have no entry and the new code maps absence to NotReached, documented as "an enclosing short-circuit skipped the implication itself". It is false there: the implication was evaluated for every element. Mutations on clause.rs against the new test: child order not reversed (killed), Entered/Skipped swapped (killed), implication/consequent regions swapped (killed), never populate (killed), events dropped is covered by the len==3 assertion (killed). Survived: removing the `truth().is_some()` gate (M4, FND-005).
