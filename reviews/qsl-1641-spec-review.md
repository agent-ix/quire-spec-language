## Verdict

**NOT MERGEABLE as written.** Four high findings: an unsatisfiable atom-index AC that contradicts an unamended FR-515 AC, an undeclared change of atom identity for shared sub-terms, a window-aggregate scope cut the package bytes do not require, and a recursive-type refusal gated on a ticket that is already Done. Four medium gaps in what the bytes must supply and in the reader-view prerequisites follow.

## Behavior-changing decisions

1. Atom index by `formula_graph()` pre-order position: direction accepted (a package has no arena), execution wrong; see FND-001 and FND-002.
2. Package component of `LedgerBinding` and `result_identity` becomes `package.name()`: accepted. FR-502 already defines the binding by "the checked package identity", `CheckedPackageV2::name()` exists, and pre-release rules allow the break. `LedgerBinding.package` is also used by the spine route in `temporal/ledger.rs`, so the type change reaches beyond the evidence route.
3. `identities.json`: consistent with FR-390 and QSL-1377 (Done); see FND-009 for what is missing.
4. No `clause-unreadable` source cross-check on the bare route: accepted. The formula comes from the same admitted bytes; the `predicate_leaves()` versus `holds` count check remains.
