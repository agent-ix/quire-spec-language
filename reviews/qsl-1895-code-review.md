## Summary

Ticket: QSL-1895 (ADR-036 slice 3). Code review with the rust-review lane folded in. The engine reads only through `protocol_view` (PA-3), builds no transition system (PA-22), never enumerates interleavings, and orders everything with `BTreeMap`/`BTreeSet` and `CheckedNodeId`/`PortRef` order (PA-15). Every PA-21 construct the profile scan finds returns `Unsupported` with no graph. A horizon cut is `Inconclusive`, run limits are `Failed` naming the limit and value, the kind stays unserved, and no settlement or manifest is wired. Two reviewer probes, run locally and not pushed, show two inputs where projection returns `Proved` but the role cannot tell the branches apart. Those are the blocking findings.

## Scope and evidence

The review covered the diff `origin/main...HEAD` at c75876074 only. The focused run (`cargo test -j2 --test it protocol_projection` in qsl-analyze, own target dir) passed the PR's 15 tests. Two reviewer probes were appended locally and not pushed: `probe_nested_choice_hides_outer_divergence` and `probe_partial_carrier_informs_role` both returned `Proved` where a counterexample is required (FND-001, FND-002).

Rust lane: no `unsafe`, no Tokio, no recursion except `Reader::walk` (bounded by the checked package's control nesting), and every public item is documented. The `unreachable!` in `project` follows a builder that always returns a projection key; the two in `execute.rs` mirror the existing `ModelGraph` arm. `Bits` indexing is in range by construction. The new `#[trace]` tags all sit on tests that call new API, so none passes without the code. There are no `/// Trace:` lines.

Checked and clean: ascending UTF-8 label order (FR-466 sorts `cases`/`branches` in the package, and `String` `Ord` is bytewise); the PA-11 rank (length, choice, path A, path B); path A ordering and `trace_position = path_a.len() - 1`; `proved` carries no certification claim beyond the slice-2 `Uncertified` variant; no settlement or manifest wiring. Every PA-21 construct is caught: `replication`, symbolic capacity, compensation template, and the `repeat`, `await` (always timed in FR-466), `compensate`, check/attempt/effect/event/commit/fence controls, non-`all` joins and `outstanding`, and a protocol-owned choice. Undecided guard outcomes cannot become a silent false: the engine ignores guard values and treats every case as reachable.
