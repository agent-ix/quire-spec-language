# SR-13656: Code review of quire-spec-language PR #1136: QSL-923

## Summary

Ticket: QSL-923. This review covers code-review and its rust-review lane. The change is one block in `Ir::reachable` (qsl-eval/src/automaton/formula.rs:464-473). For every reachable `Or`, it interns the negation of each state operand and puts it in `order`, so `truths` evaluates it. The `or` rule's `exclude` (translate.rs:910-913, 1087-1092) asserts that negation. The source fix is correct and complete. Two of the three new HP-2 tests in hyper.rs cannot fail on the defect, and the PR's claim that shape 2 does not reproduce on main is wrong.

Evidence:

- **Completeness of the fix.** `exclude` is called from the `or` rule (left operand; right operand when the left has a future), from `eventually` and `until` (witness), from `release` (guard), and from the interval counters (translate.rs:956, 964, 978, 1028, 1052). Every operand of the other call sites is an operand of a future operator, which `reachable` already covered. The `or` operands are the only gap, and the fix covers both sides. A negation always has a larger index than its operand (`not` of a `Not` returns the smaller operand), so `truths` reads the operand first. The new `Not` nodes never enter a `Config`, which holds future nodes, counters, shifts and past memory, so state numbering, `exchanged` and the automorphism check are unchanged. No pinned state count moved.
- **Independent automaton oracle** (reviewer-written lasso semantics, not the coder's; files under the scratchpad's rv1136-probe worktree). It covers or, and, implies, not, constants, eventually, always, until and release (open, `[1,*]`, `[0,1]`, `[1,2]`, `[1,1]`), and once, historically, since and triggered with the stationary all-false history. Past values are computed on an unrolled lasso and checked to have settled. It is compared with my own Tarjan acceptance check in 7 modes: `translate` clause, `translate_body`, `translate_negation`, `translate_negation` in normal form, "itself" (the negation of `not body`), itself in normal form, and `on each ... when` activation. It ran every lasso up to stem 3 and loop 3 (2 atoms) and stem 2 and loop 3 (3 atoms). There are 19 fixed shapes (both repro shapes, nested `or`, `not` over temporal formulas, constants under temporal operators, past operands) and 4 seeds of 80 random bodies (7, 11, 23, 41). In all, 99.5M lasso comparisons, with 0 disagreements, and 0 disagreements against the clause evaluator in clause mode. 320 random bounded `or` bodies agree with the evaluator. With the fix reverted, all three oracle tests fail.
- **Hyper brute force.** The probe uses random vault models and random `or` bodies with past operators and intervals. It brute-forces over joint lassos with the oracle above. HP-2 (`forall a` and `forall a forall b`), 1120 cases over 6 seeds: 0 false Holds; every Violated counterexample closes, falsifies the body and replays. HP-3 (`forall a exists b`, safety bodies), 1120 cases: 0 false Violated. HP-6: the earlier `align skip` oracle (rv1121) with an `r or always q` disjunct added, 600 cases: 0 mismatches. Copy-swap (rv1123 probe) with 6 `or` bodies added, 400 cases: 400 agree, 0 skipped. On the merge base 9c8c9b102 the same probes find 1 false Holds (HP-2), 23 false Violated and 10 internal faults (HP-3), 58-68 mismatches per seed (HP-6, `the-evaluator-confirms` invariant refusals), and 22 copy-swap runs refused with `Fault(hyper-product, a-reached-automaton-state-expands)`. No earlier HP-2, HP-3 or HP-6 verdict moved other than the defect's.
- **HP-5 on #1131** (qsl-556-hp5 4943555dd merged with this head, da98c56ea). `exists trace b of V { holds(v.l @ b = 1) or always holds(v.l @ b = 0) }` (step requires l=0 and sets l=i, reset requires l=1 and keeps l=1, start (1,0)) is `Witnessed` with `witness_samples` 0, and under every fairness and start set tried. Before the fix it was `Trapped(0)`. Shape 2, `(not p1) or ((p1 until p1) or (p1 or p1))`, through `translate_itself` now has successors on every letter; before, it failed with `Invariant{negation-interned}`. The #1131 brute-force oracle over seeds 11, 23, 41, 53 and 67 (60 cases each) gives 0 QSL-923 discrepancies (seed 67 had 4 before). The only remaining ones are the key-order trap-versus-Undefined oracle artefact already recorded in SR-13627.
