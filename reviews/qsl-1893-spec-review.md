# spec-review of protocol analysis requirements FR-570..FR-575 (quire-spec-language PR 2689)

## Summary

Ticket: QSL-1893. Method: spec-review. Diff: `git diff origin/main...HEAD` at 47ca5f0de4f20e2f6c299dad23e60da56554ddf4, 12 files, spec-only.

Fidelity review against ADR-036 PA-1..PA-25 and QSpec FR-174, FR-175, FR-207, FR-351, FR-360, plus quire-protocol FR-302 and FR-152. Every PA that is a requirement maps to an FR: PA-3/5/6/9-12/25 to FR-570; PA-7/8/16-19 to FR-571; PA-13-15 to FR-572; PA-12/14/20 to FR-573; PA-24 to FR-574; PA-21/22 to FR-575. PA-1, PA-2 and PA-23 add no requirement, and PA-4 appears only as the 'no new NegotiationCause variant' ACs. No invented requirement found. FR-174-AC-1..6 and FR-175-AC-1..6 are each cited by an AC. FR-573's map agrees with FR-360's FR-241/242/243 combination for all five labels. Author choices: the profile word `bounded-static` matches PA-21. The eight slugs are sound (see the integrity review for a precedence gap). Refusing a wrong profile word with `invalid_runtime_input`/`invalid-value` naming `profile` is consistent with FR-572's `missing-member` for the same key member; FR-054 names no code, so this does not conflict with PA-21's analogy. FR-207 pin: ruling recommended is ACCEPT empty steps with the node identified by deciding_element. It is the least-invention path, a valid FR-207 path (AC-4), and safe for byte-exact import because FR-302/FR-152 copy and never recompute. The defect is only the undefined root (FND-001).
