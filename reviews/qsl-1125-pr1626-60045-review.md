# Final re-verify over PR 1626 (QSL-1125 = QSL-1121b), head 6ec88ffb2

## Summary

Verdict PASS with low findings only. SR-60044 FND-001 is closed: `equality_stable` in QSL is a faithful mirror of the pinned reader's rule, and a 60-case probe beyond the coder's list found no mismatch in either direction. No high or medium finding.

Method. Reader read at quire-contract-ir 9a84e654 (`protocol_body.rs`: `equality_stable` at 1261, `collect_type_children` at 1436, the FIFO check at 2059), compared line by line with QSL's `equality_stable`. Then a scratch probe (not pushed) ran 60 FIFO-key cases through QSL's check as shipped, and again with `fifo_key_unstable` patched to admit everything so the reader's own verdict showed for every case (QSL admits: emit and read back; QSL refuses: emit with the guard off and read the reader's verdict).

(1) Fidelity. Same rule: scalar Boolean, Integer, Rational, Decimal, Text, String, UUID, Timestamp, enum and composite `reference` are stable; any other composite is stable when every child is; every other node kind is unstable; a visited set bounds the walk. Two structural differences, both unreachable: the reader returns false for a node it cannot index, QSL continues (reachable only for a nominal enum, whose declaration node is written with the declarations; the coder's note), and the reader refuses a composite body term that is not a reference, aggregate, binding or literal while QSL walks every key of the body (a composite body QSL builds is only an aggregate of references and bindings of groups of references, so no other term occurs). The reader reads the key's type from the key term's node; QSL reads the checked key's value type; both agreed on every case, including compound keys (`m + m`, `m + 1`, `-m`, `not m`, `m = 1`, literals `1` and `true`).

Probe, QSL verdict = reader verdict in all 60: admitted by both: Set, Bag and OrderedSet of Integer, String, Color, Plain record, Reference<M::Order>; Option<Reference>; Sequence<Reference>; Option<Option<Integer>>; Option<Timestamp>; Sequence<Timestamp>; a record of a record of Integer; records with a Sequence of records or an Option<Integer> field; tuple (Integer, String); union with Integer payload; Option<union>; projections m.p, m.p.x, m.w.x, m.o.w.x, m.q (Option<Integer>), m.s; keys `m + m`, `m + 1`, `1`, `true`, `m.x + 1`, `m.b + 1` (a bounded Int plus one is Integer), `m = 1`, `-m`, `not m`. Refused by both (reader `ill_typed`): Set<Quantity>, Bag<Int[0,5]>, OrderedSet<Text bounded>, Set<record with quantity>, Option<Option<Int[0,5]>>, Option<Option<Quantity>>, record of record of quantity, record of record of bounded Int (two and three levels), Sequence of record with Text, Option<Quantity> field, tuple with a bounded Int, union with a bounded Int or a quantity payload, Option<union with bounded>, Sequence<union with bounded>, projections m.w, m.w.q, m.w.b, m.o, m.o.w, m.o.w.b, m.s (Sequence of Text records), m.q (Option<Quantity>), and `m + m` over a quantity. Not constructible: a bare Rational, Decimal, Text, a Duration, a Population carries (the grammar always bounds the first three; `Reference<M::Order>` as the carries is refused earlier as `ChannelCarriesObject`; `m.b = m.x` refuses `KeyClause` type mismatch before the guard). Float is refused earlier as bounded. Model-owned families (Tier, Odd, Settings, m.tier, Sequence<M::Tier>) are covered by the coder's test over the variant document and read as refused in the SR-60044 probe; they were not re-probed.

(2) Durable reader proof of the refusals. The refusal tests prove QSL's verdict and that no clause node is written; only the admitted cases are read back by the reader. The reader's refusal of the 20 refused bodies has been proved by a manual probe (SR-60044, this one) and not by a kept test. A kept test would need the guard bypassed across the qsl-semantics/qsl-package crate boundary (a `cfg(test)` switch does not cross crates), or a hand-built wire; not trivial. Low (FND-001).

(3) Mutation pass on the key guard, run against the `protocol_graph` tests. Killed: drop Boolean, Integer, String, UUID, Timestamp arms; composite not walked; bounded domain treated stable; model-owned treated stable; quantity treated stable; unknown node treated unstable (`None => return false`); every unknown kind treated stable; guard disabled; guard also applied to unordered channels. Survived: drop Rational, drop Decimal, drop Text, drop enum. All four are unreachable by construction, not a test gap: QSL lowers Rational, Decimal and Text only as a base under a `bounded_domain` (which the walk refuses before reaching the base), and a nominal enum is the declaration node that is never in the graph at that point. They are dead arms that mirror the reader (FND-003).

(4) Conventions. `quire validate` of FR-383 and FR-092 exits 0 (tool warnings only). No `#[allow]` in the new production code; the only wildcards are on the `semantic_form` string of a tag that is otherwise exhaustive. Refusals are typed (`ChannelKeyNotEqualityStable`, `ChannelCarriesBounded`). FR-383 staged paragraph and the QSL-1137 and QSL-1142 text agree with the code. The five tests added for the carries and key families (`a_channel_carries_every_type_the_reader_admits` and the four after it) carry no `#[trace]` attribute (FND-002). QSL-1142 in Linear still carries the title "QSL check admits it, IR reader refuses (ill_typed)", which describes the pre-fix state (FND-004). QSL-1137 is clean.
