# Deletion table for the Layer 4 old-architecture units

This is the row-level table for the units the Layer 4 deletion train removes (D-S2, 2026-11-04, QSL main 0642337ef). It refreshes the 326-row code-derived inventory against main. ADR-011 "Deletion order of the remaining old-architecture units" fixes the order. FR-499 owns the per-unit dispositions, FR-500, FR-513 and FR-525 map legacy criteria to successors, and FR-521 owns the quire-protocol gate.

## Status words

- GREEN: every successor criterion named in the row is tagged by a test outside the deleted files, and each of those tests passed by name on main (`cargo test --workspace`).
- TICKETED: a successor exists in part; the uncovered criteria are named and a named open ticket owns them.
- KEEP: the file or surface stays (a gate or a consumer names the condition).
- RETIRE-RULED: the behavior ends with its carrier under a ruling cited in the row. No successor test exists. The owner sees these rows as sunsets.
- NO-SUCCESSOR: no green successor test and no open ticket. The behavior is listed in Part C with a recommendation.
- RED: a successor test fails on main.

## Method and limits

- Rows come from six code-derived inventories taken at main e7b7a57e3 (temporal, native_model, protocol_artifact B8/B9, composed Protocol family, composed lane, native-compile/1). Each row was re-mapped to successor criteria through FR-499, FR-500, FR-513, FR-521 and FR-525, and each criterion resolved through `quire matrix --scope .` to the test that tags it.
- A binder counts as a successor only if its file does not import a deleted module and is not `#[ignore]`d. GREEN also requires the test to pass by name in `cargo test --locked --workspace --no-fail-fast` on this head.
- GREEN means the named criteria are tested, not that the criteria exhaust the old behavior; where the inventory said PARTIAL, the row names the missing part or stays TICKETED or NO-SUCCESSOR.
- Main is not fully green: `cargo test --workspace --no-fail-fast` on this head had 19 failures outside every successor test named here: 14 in `qsl-replay` (`spine::clause::tests::layers::equality::*` and `frame_occurrence_region_is_the_first_naming_clause_or_attempt_in_source_order`), 4 in `qsl-semantics` or `qsl-package` family-resolution tests (`a_family_with_no_body_for_a_concrete_subtype_refuses_at_s3`, `a_unit_with_several_ambiguous_families_is_refused_once_naming_each`, `an_unrelated_family_of_the_same_name_refuses_only_when_a_call_reaches_it`, `unit_compile_refuses_a_family_past_the_callers_family_steps`) and `model_conformance_boundary::c06_two_selections_canonical_order`. Feature-gated successors (`checked_handoff`, `mapping_support`) were run with `--features checked-handoff,handoff-writer`.
- Temporal rows ticketed to QSL-1380 are an umbrella ticket ("add successor spine tests where missing"), not a per-criterion ticket; the Note column lists the criteria that still need one.
- native_model rows marked RETIRE-RULED rest on the FR-499 native_model table and planner decision 5; they are listed so the owner sees every sunset.
